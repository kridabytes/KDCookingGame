# Refined home screen UI sprites

Unity-ready, individual transparent sprites generated to match the pink, cream, gold and green cooking-game demo. Each PNG has Sprite (2D and UI) import metadata and mipmaps disabled.

Includes a generic star icon button, a complete No Ads button, a complete Play button, the blank main top panel, an energy capsule, and a separate energy bolt icon. The bolt can be layered over the capsule if you prefer to place it independently.
