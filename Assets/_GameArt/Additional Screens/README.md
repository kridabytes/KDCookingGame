# Additional Screens

Sprite drafts for the language selection, shop, daily tasks, achievements, and free gift screens, plus common UI pieces. Each screen folder also contains its matching full-screen `*_Demo.png` concept. `Common UI` includes a shop screen reference showing the shared chef, background, currency HUD, and popup style. See [CLAUDE_HANDOFF.md](CLAUDE_HANDOFF.md) for Unity integration notes and the current transparency limitation.
