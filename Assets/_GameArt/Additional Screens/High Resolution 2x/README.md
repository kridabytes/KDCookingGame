# Common Popup Kit — High Resolution 2× Sheets

These are 2× Lanczos-resampled copies of the original transparent atlases and standalone progress-bar layers. Every sprite retains the original layout and has twice the width and height in source pixels. The originals remain unchanged in `../`.

## Contents

- `Additional_Popup_Icons_Sprite_Sheet_2x.png` — currency, food, booster, flag, navigation, and status icons.
- `Common_Popup_Props_Sprite_Sheet_2x.png` — popup frames, ribbons, buttons, and shared props.
- `Reusable_UI_States_and_Separators_Sprite_Sheet_2x.png` — state controls, separators, and progress bar components.
- `Remaining_UI_Items_Sprite_Sheet_2x.png` — screen-specific blank rows, cards, buttons, reward tiles, and completion/progress components.
- `Progress Bar/` — 2× background track, fill, and assembled example as separate PNGs.

The longest atlas edge is 3548 px, below a 4096 px texture cap. This is a high-resolution resample of the current artwork, not a redraw that adds new painted detail; the source art and sprite design are preserved. Set Unity's Max Size to at least the image's imported dimensions if you use these versions. Progress track and fill should remain separate runtime layers.
