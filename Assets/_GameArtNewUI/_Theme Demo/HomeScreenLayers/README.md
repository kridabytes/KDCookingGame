# Home screen theme layers (Unity sprites)

Each PNG is imported as an individual Sprite (2D and UI), with mipmaps disabled. Arrange and scale the layers in your existing landscape scene.

Suggested back-to-front order:
1. Island water/shore base (full scene background; already includes sand, grass, palms and shoreline decoration)
2. Road network and/or river curve (position and scale to suit your map)
3. Restaurant buildings
4. Palm and balloon decorations
5. Top panel background, counter/button shells, menu controls, plus icon and play button

The assets are newly generated style-matched demo components, not pixel cutouts of the reference screenshot. The road network may need positioning/cropping to fit your chosen island composition. Add labels and resource icons as separate Unity UI/text elements.
