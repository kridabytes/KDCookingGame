# Wave Animation

The wave loop shows the chef facing forward with a happy expression, waving one hand while the other rests on her waist.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Wave_Animation.png`: 21-frame sprite sheet, 4 columns × 6 rows, 1536 × 3072 PNG with transparent background; each frame cell is 384 × 512 pixels.
- `1_Wave_Animation_Preview.gif`: looping preview of the frames in sequence.

Add future wave variants with the next number (for example, `2_Wave_Animation.png`).
