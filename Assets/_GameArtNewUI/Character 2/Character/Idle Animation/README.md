# Idle Animation

The idle loop shows the chef in a 3/4 view facing right, with gentle breathing, small presenting and waving gestures, and a blink.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Idle_Animation.png`: 21-frame sprite sheet, 4 columns × 6 rows, 1536 × 3072 PNG with transparent background; each frame cell is 384 × 512 pixels.
- `1_Idle_Animation_Preview.gif`: looping preview of the frames in sequence.

Add future idle variants with the next number (for example, `2_Idle_Animation.png`).
