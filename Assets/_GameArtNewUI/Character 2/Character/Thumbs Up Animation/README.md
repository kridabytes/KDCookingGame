# Thumbs Up Animation

The chef leans in with a confident thumbs-up from her right hand, winks on frame 6, then finishes with a small bounce.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Thumbs_Up.png`: 21-frame sprite sheet, 4 columns × 6 rows, 1536 × 3072 PNG with transparent background; each frame cell is 384 × 512 pixels.
- `1_Thumbs_Up_Preview.gif`: looping preview of the frames in sequence.
