# Character Animations

This folder stores the chef character's animation sprite sheets and previews.

All sprite sheets use 384 × 512 pixel frame cells, with five breathing/blink frames appended in the pose of each animation's last action frame. Character height and foot baseline are normalized across the added frames while preserving natural pose width. Sheets originally containing 16 action frames now use 4 × 6 grids (1536 × 3072); those with 8 action frames use 4 × 4 grids (1536 × 2048). Celebration has 19 frames in a 4 × 5 grid (1536 × 2560) after removing the hands-down sprite.

## Animation folders

- [Idle Animation](Idle%20Animation/README.md): subtle idle loop with small presenting gestures.
- [Wave Animation](Wave%20Animation/README.md): front-facing happy greeting wave.
- [Sad Animation](Sad%20Animation/README.md): gentle sad/disappointed loop that shifts back toward hopeful.

Animation image files are numbered from `1` within each animation folder so additional variants can be added with the next number.
- [Chef's Kiss Animation](Chef's%20Kiss%20Animation/README.md): fingertip kiss and outward sparkle gesture.
- [Thumbs Up Animation](Thumbs%20Up%20Animation/README.md): confident right-hand thumbs-up with a wink.
- [Tasting Animation](Tasting%20Animation/README.md): spoon tasting and satisfied reaction.
- [Mini Dance Animation](Mini%20Dance%20Animation/README.md): cute 8-frame side-to-side dance loop.
- [Hat Fix Animation](Hat%20Fix%20Animation/README.md): straightens a tilted hat and giggles.
- [Twirl Animation](Twirl%20Animation/README.md): joyful half-spin and front-facing finish.
- [Heart Hands Animation](Heart%20Hands%20Animation/README.md): hand-heart gesture with a small floating heart.
