# Twirl Animation

An 8-frame joyful half-spin in place, with the apron skirt flaring and the chef settling front-facing with one hand on her hip.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Twirl.png`: 13-frame sprite sheet, 4 columns × 4 rows, 1536 × 2048 PNG with transparent background.
- `1_Twirl_Preview.gif`: looping preview of the frames in sequence.
