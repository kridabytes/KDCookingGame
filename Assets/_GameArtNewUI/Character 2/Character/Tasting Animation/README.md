# Tasting Animation

The chef tastes from a small wooden spoon, savors the flavor with closed eyes, does a tiny shoulder shimmy, and ends with a satisfied “mmm” expression.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Tasting.png`: 21-frame sprite sheet, 4 columns × 6 rows, 1536 × 3072 PNG with transparent background; each frame cell is 384 × 512 pixels.
- `1_Tasting_Preview.gif`: looping preview of the frames in sequence.
