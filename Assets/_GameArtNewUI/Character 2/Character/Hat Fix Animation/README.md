# Hat Fix Animation

An 8-frame animation of the chef noticing her tilted hat, straightening it with both hands, then giggling behind one hand.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Hat_Fix.png`: 13-frame sprite sheet, 4 columns × 4 rows, 1536 × 2048 PNG with transparent background.
- `1_Hat_Fix_Preview.gif`: looping preview of the frames in sequence.
