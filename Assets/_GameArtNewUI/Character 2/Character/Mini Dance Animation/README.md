# Mini Dance Animation

An 8-frame loop of a cute side-to-side dance with small heel pops, happy fists, and bouncing curls and apron bow.

The final five frames reuse the last action pose, adding subtle breathing and one blink. Each cell remains 384 × 512 pixels; the unused final three cells are transparent. The preview holds these idle frames longer.

- `1_Mini_Dance.png`: 13-frame sprite sheet, 4 columns × 4 rows, 1536 × 2048 PNG with transparent background.
- `1_Mini_Dance_Preview.gif`: looping preview of the frames in sequence.
